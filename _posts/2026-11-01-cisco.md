# Common Cisco Commands
**OSPF Configuration**
```
RA# show ip ospf neighbor
Router(config)# router ospf process-id
Router(config-router)# router-id rid
Router(config-router)# network network-address wildcard-mask area area-id # Configure the routing process on R1 with the network statements and wildcard masks that are required to activate OSPF routing for all the attached networks.
```
