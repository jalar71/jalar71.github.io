## Cyber Terms/Glossary

Tarpit 
: A tarpit is a cyber defense mechanism designed to purposely slow down incoming network connections from attackers or scanners. [Reference](https://d3fend.mitre.org)
Inline AV (Inline Antivirus/Anti-Malware)
: An inline AV is a security tool or feature integrated directly into the physical or logical path of network traffic. <br> [Reference](https://d3fend.mitre.org)
**The Goal**: To scan, detect, and block malware in real-time as data moves through the network, before it reaches its final destination (like a user's computer).
Queuing
: Queuing is a network traffic management strategy used to temporarily hold and organize data packets when a network link or server becomes congested. [Reference](https://d3fend.mitre.org)
DNS Redirect Tactics (DNS Redirection/Sinkholing)
: DNS redirect tactics involve intercepting a user's Domain Name System (DNS) request and sending back a different IP address than the one originally requested. [Reference](https://d3fend.mitre.org)
